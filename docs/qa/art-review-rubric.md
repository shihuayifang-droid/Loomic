# 美术人工评审口径：放大画质盲评与快捷编辑效果基准（QA-14）

本文件定义两件事：**放大画质的盲评怎么做、评什么、怎么给分**；以及**快捷编辑（亮度 / 对比 / 裁剪 / 滤镜等）的「合格」判据**。评审必须由美术本人执行，本规范只固定口径，使不同人、不同批次的结果可比较、可直接进验收。

- 样本引用一律用脱敏 ID（`sample-01`、`sample-02`…），不写真名、不写订单号、不写任何账号或内部地址。
- 评审人代称用 `artist-a` / `artist-b`。
- 一次评审 = 一个批次；批次标识与日期写进记录表。

## 1 放大画质盲评

### 1.1 盲评怎么组织

1. **随机顺序**：把一个批次内的全部样本按盲评序号打乱排列（用固定随机种子生成一次顺序表，记录种子，供复核时复现同一顺序），**评审人只看到盲评序号，看不到样本原始名称、处理类型、来源与上一轮分数**。
2. **去水印**：样图上的水印、角标、工具名、批次编号一律抹除或裁掉；抹除区域若与被评区域重叠，该样本作废重出。
3. **去元信息**：清除图片元数据（EXIF / IPTC / 注释块）与文件名中的处理痕迹，文件名统一改成盲评序号；不让评审人从文件名或元数据反推出是哪个流程的产物。
4. **同屏同尺寸**：同一组对比样本在同一显示器、同一缩放倍率下查看，禁止临时缩放比较；放大倍率固定写进记录（默认 2 倍，必要时 4 倍）。
5. **一次只评一项**：先做完放大画质盲评并封存分数，再做其他维度的评审，避免后看到的样本影响前面的判断。
6. **两名美术独立评**：`artist-a` 与 `artist-b` 各自独立完成盲评，互不看对方分数；同一盲评序号两人分差 **大于 1 分** 时必须一起回看原图并记录复核理由。

### 1.2 评什么（四个观察项）

| 观察项 | 看什么 | 放大倍率 |
|---|---|---|
| 边缘 | 轮廓是否干净：有无锯齿、描边断裂、边缘光晕、双线重影；主体与背景交界处是否糊成一圈 | 2 倍，问题处 4 倍 |
| 噪点 | 平坦区域（皮肤、天空、纯色背景）是否出现彩色噪点、色带、涂抹感；暗部是否堆噪 | 2 倍 |
| 伪影 | 有无不该出现的东西：振铃、块状压缩痕、错位拼接缝、重复纹理、AI 生成特有的结构性错误 | 2 倍，问题处 4 倍 |
| 纹理保真 | 布料、毛发、金属、皮革的纹理是否还在，有没有被抹平成塑料感；纹理尺度是否与原图一致 | 2 倍 |

### 1.3 打分口径

四观察项各自 1–5 分整数，再取算术均值作为该样本的放大画质分。分档如下（四观察项共用同一把尺）：

| 分数 | 判据 |
|---|---|
| 1 分 | 不放大就能看出问题；放大后观察项严重失效（边缘全糊、大片噪点、明显错位伪影、纹理完全丢失） |
| 3 分 | 正常观看无感，放大到 2 倍后在问题区域能看到该观察项的轻微退化，但不影响整体阅读 |
| 5 分 | 放大到 2 倍（必要时 4 倍）观察项完全成立：边缘锐利无光晕、平坦区无噪、无伪影、纹理尺度与原图一致 |

> 上下文中出现的问题必须在记录表「问题」列写明**盲评序号 + 观察项 + 位置**（例如「放大后左肩轮廓可见 1 px 光晕」），否则该分数不计入汇总。

## 2 快捷编辑效果基准口径

每类编辑都要先定义「输入是什么、输出应该变成什么」，再定义「合格」判据。**合格判据必须是可复核的观察结论，不能是「看着不错」。**

### 2.1 亮度

- 定义：整体提亮或压暗，保持色彩关系与对比结构基本不变。
- 合格判据：目标区域的中位亮度朝预期方向移动且**未出现截断**（大面积为纯白或纯黑）、暗部细节与高光细节至少各保留一档、色彩关系（相对色相）不偏移。
- 典型不合格：高光糊成一片白、暗部压死成黑板、提亮后整图发灰发脏。

### 2.2 对比

- 定义：拉大或压缩亮暗差，改变影调分布而不改变色彩倾向与内容。
- 合格判据：直方图两端朝预期方向展开或收拢、中间调不发生整体色偏、加强对比后高光与暗部仍留有细节、不产生色带与断层。
- 典型不合格：加强对比后高光溢出成色块、暗部出现条带、肤色偏色。

### 2.3 裁剪

- 定义：按指定比例或指定区域裁切，重定位主体，不改变像素内容与色彩。
- 合格判据：输出比例与要求一致（误差 ≤1 像素）、主体完整且在安全区内、裁切边界无拉伸与重复、无黑边与半像素错位、像素内容与源图对应区域一致（不重采样变形）。
- 典型不合格：比例对但主体被切掉、边缘出现拉伸、裁出了源图外的黑边。

### 2.4 滤镜

- 定义：按预设风格整体调色或改质感，输出应保持主体可辨、结构与纹理不丢。
- 合格判据：风格方向与预设一致、主体识别特征未被破坏、平坦区不出现色带与噪点放大、边缘不出现光晕或描边、纹理可比对出对应关系（不是整片涂抹）。
- 典型不合格：滤镜把脸糊掉、边缘出现一圈亮边、整图噪点被放大。

### 2.5 其他编辑类型

新增编辑类型时按同一格式补一条：**定义 → 合格判据 → 典型不合格**，并写明该类型参与汇总时的权重。未写进本文档的编辑类型不纳入评审。
