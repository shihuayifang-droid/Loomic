# 角色一致性三维评测评分规范（QA-06）

本文件是**人工评分的执行规范**：美术拿到同一角色在 10 个场景下的出图，按下面三维逐张打分、双人独立复评、按固定口径汇总，结果直接作为 QA-06 的验收证据。

- 评测对象：同一角色（同一份角色设定）在 10 个不同场景下的产出图。
- 评测人：**2 名美术**（互相独立，规则见第 4 节）。
- 评测性质：**人工评审，必须由美术本人执行**；本规范只定义口径，不代替评审。
- 记录落盘：评分表按第 6 节格式保存，文件名形如 `qa06-<角色代号>-<日期>.md`，角色代号用 `sample-01` 这类脱敏 ID。

## 1 三维定义

三维分别覆盖「像不像这个角色」「细节经不经得起看」「风格与光照是否自洽」。每维 1–5 分，**只允许整数分**。每维的 1 分 / 3 分 / 5 分必须按下表对照，2 分和 4 分取相邻两档之间。

### D1 角色识别一致性（Identity）

判的是：把这张图单独拿出来给没看过设定的人，能否认出是同一个角色。

| 分数 | 判据 |
|---|---|
| 1 分 | 关键识别特征缺失或互相矛盾（例如标志性配色错、标志性配饰缺失、脸型与设定明显不同），不看文件名认不出是哪个角色 |
| 3 分 | 关键识别特征基本都在，但存在 1–2 处明显偏差（配饰比例不对、发色偏色、瞳色偏移），熟悉设定的人能认出，陌生人需要提示 |
| 5 分 | 关键识别特征全部准确，比例、配色、配饰位置与设定稿一致，陌生人可直接认出 |

### D2 结构细节保真（Detail）

判的是：放大看之后，结构、解剖、材质是否成立，有没有糊、有没有崩。

| 分数 | 判据 |
|---|---|
| 1 分 | 结构错误肉眼可见（肢体数量或连接错误、手指数量错误、面部五官错位、配饰穿模），或主体大面积糊成色块 |
| 3 分 | 主体结构成立，但局部细节经放大后出现轻微崩坏（远端手指粘连、边缘毛刺、材质纹理丢失），不影响整体阅读 |
| 5 分 | 放大到 2 倍仍无结构错误，边缘干净、纹理与材质可辨，配饰与主体的贴合关系正确 |

### D3 风格与光照一致性（Style & Lighting）

判的是：这张图是否与同一角色的其他场景看起来像「同一次出图」，风格与光照自洽。

| 分数 | 判据 |
|---|---|
| 1 分 | 风格明显跳变（线条粗细、上色方式、渲染质感换了一套），或光照方向、色温与场景设定冲突导致角色像贴上去的 |
| 3 分 | 风格基本统一，但光照方向或色温有偏差，阴影与高光与场景不完全吻合 |
| 5 分 | 风格与设定完全统一，光照方向、色温、阴影软硬程度与场景设定一致，角色与环境的光影关系正确 |

## 2 场景清单（10 个用例）

同一角色固定跑下面 10 个场景，**场景编号即记录用的行号**，不得增删或换序。

| 场景编号 | 场景描述（景别 / 姿态 / 光照 / 风格） | 验收关注点 |
|---|---|---|
| 场景 01 | 特写 / 正面站立 / 中性柔光 / 标准设定风格 | 面部三庭比例与设定稿一致；瞳色、发色、标志配饰与设定稿逐一对应；眼睛与口腔结构无错位 |
| 场景 02 | 近景 / 3/4 侧身 / 室内暖光 / 标准设定风格 | 侧脸轮廓与设定稿一致；近侧配饰遮挡关系正确；暖光下肤色不偏橙红失控 |
| 场景 03 | 中景 / 静态站姿 / 室外日光 / 标准设定风格 | 全身比例（头身比）与设定稿一致；服装层次与下摆形制正确；投影方向与日光一致 |
| 场景 04 | 全景 / 行走姿态 / 阴天散射光 / 标准设定风格 | 动态下四肢关节数正确；衣料褶皱随动作成立；散射光下无强反差导致的细节丢失 |
| 场景 05 | 近景 / 坐姿 / 低角度仰拍 / 标准设定风格 | 仰拍下透视缩短合理；下身与座椅接触关系不穿模；下巴与颈部结构不失真 |
| 场景 06 | 中景 / 战斗姿态 / 强对比侧逆光 / 标准设定风格 | 逆光下轮廓与边缘光成立；武器握持手型正确；高对比不吞掉面部识别特征 |
| 场景 07 | 特写 / 表情变化（愤怒） / 夜景冷光 / 标准设定风格 | 表情变化后仍保持同一角色识别特征；夜景冷光下配色偏向可接受；牙齿与眼部细节不崩 |
| 场景 08 | 全景 / 奔跑姿态 / 黄昏逆光 / 标准设定风格 | 奔跑动作的肢体重心与落地脚正确；逆光剪影仍能辨认配饰轮廓；黄昏色温下肤色不脏 |
| 场景 09 | 中景 / 半身回望 / 顶光 / Q 版比例风格 | 切到 Q 版比例后识别特征仍成立；顶光下额头与鼻影不过度；比例切换不带来配饰比例错乱 |
| 场景 10 | 近景 / 持物展示 / 混合环境光 / 标准设定风格 | 手持道具与角色风格统一；道具与手部贴合无穿模；混合光源下无双重硬阴影冲突 |

## 4 两名美术独立打分规则

1. **各自独立出分**：两名美术各自持有一份空白矩阵，**先各自独立填完 10 个场景 × 三维的全部 30 个分数**，期间不得查看对方的任何分数与备注。
2. **不得事前对齐**：打分前不得就某张图「大概给几分」进行口头沟通；可以就「这个场景应该在什么景别下看」这类口径问题沟通，不得就分数沟通。
3. **收齐后再比对**：两人都填完后，由第三方（本项目主 Agent 或验收人）把两份矩阵并排比对。
4. **分歧 >1 分必须复核并记录理由**：同一场景同一维度两人分差 **大于 1 分**（即相差 2 分及以上）时，两人必须一起回看这张图的原图（放大到 2 倍），重新各自给分；复核结论写入「分歧复核记录」表，理由必须指向图上的具体区域。
5. **分差 ≤1 分不强制复核**：直接按第 5 节口径取均值。
6. **不得事后改分凑均值**：复核后两人的分数各自保留，只在「结论分」列写复核采用的分数，并标注采用谁的分或两人重给的分。

## 5 汇总口径与判定阈值

- **三维各自均值**：`该维均值 =（美术 A 该维 10 个场景分数之和 / 10 + 美术 B 该维 10 个场景分数之和 / 10）/ 2`，保留两位小数。
- **总分**：`总分 = D1 均值 + D2 均值 + D3 均值`，满分 15，保留两位小数。
- **单项最低分**：30 个分数（2 人 × 10 场景 × 3 维）中的最小值，单独记录。
- **判定阈值（可执行一句话）**：**每个维度的均值都 ≥3.5 分且 30 个单项分数中没有任何一项是 1 分，即判该角色一致性通过；否则不通过。**

## 6 记录与留痕格式

| 字段 | 内容要求 |
|---|---|
| 角色代号 | 脱敏 ID，形如 `sample-01`；不写真名、不写项目外可识别的信息 |
| 出图批次 | 批次标识 + 生成日期 |
| 评测日期 | 实际打分日期 |
| 美术 A / 美术 B | 用 `artist-a` / `artist-b` 这类代称，不写真名 |
| 三维均值 | D1 / D2 / D3 各一位，按第 5 节算 |
| 总分 | 三维均值之和 |
| 单项最低分 | 30 个分数中的最小值 |
| 判定 | 按第 5 节阈值写「通过」或「不通过」，并附一行算式 |
| 问题清单 | 逐条写场景编号 + 维度 + 现象，供后续修复回归 |

> 本规范不记录任何真实用户数据、账号信息、内部地址；所有样本只以脱敏 ID 引用。
